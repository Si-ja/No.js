About the library

NO.js has been developed for absolutelly no reason except to remind ourselves that we need a break from time to time and seeing our code not compile or work as intended to be not the end of the world. To embrace this philosophy, you can try and NOT build a project with NO.js yourself today!

To NOT get started with NO.js go for the documentation about it to a dedicated GitHub page. You can find it here: NO.js GitHub project . It's likely the page you came from in the first place though...weirdo. If you successfully implement the library as part of your project and initialize it - the application that you start through it should crash and stop you from running anything further.

Happy NOT coding!
